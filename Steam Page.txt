[tr][td]Settings & patches
- Accelerating Particles: enabled by default. Allows new content.
- Energy patch: disabled by default. Reduces the energy consumption of the life support system by 2x, and the small life support system by 3x.
- Odyssey Hull Graphics: disabled by default. Ship hull graphics from the Odyssey add-on.
- Odyssey Thrusters Graphics: disabled by default. Ship thruster graphics from the Odyssey add-on.
- RCS Layer Fix: enabled by default. Sets the RCS thruster render layer to "FloorEmplacement" so it looks correctly.
- Translation Patch: disabled by default. Replaces the text "Hover Mode" with "Режим парения" in the shuttle interface. Apply if want to learn some Russian words.[/td][/tr]

- антипротонный ускоритель;
- капсула с антипротоном.[/td][/tr]
[tr][td]Настройки и патчи
- Ускоряющие частицы: включено по умолчанию. Добавляет новый контент.
- Энергетический патч: отключено по умолчанию. Уменьшает энергопотребление системы жизнеобеспечения в 2 раза, а малой системы жизнеобеспечения — в 3 раза.
- Графика корпуса Odyssey: отключено по умолчанию. Графика корпусов кораблей из аддона Odyssey.
- Графика ускорителей Odyssey: отключено по умолчанию. Графика ускорителей кораблей из аддона Odyssey.
- Исправление слоя RCS: включено по умолчанию. Устанавливает слой ускорителей RCS на "FloorEmplacement" для корректного отображения.
- Патч перевода: отключено по умолчанию. Заменяет текст "Hover Mode" на "Режим парения" в интерфейсе шаттла.[/td][/tr]
